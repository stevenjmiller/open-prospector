# Transport-only fixture

This public, truth-free fixture asks the scripted fake endpoint to deliver a
stipulated synthetic marker. It is distinct from synthetic-v0 terrain and never
claims to exercise autonomy or infer mineral composition. Its fixture.json is a
fake-driver input, not a raster fixture-manifest-v0.

See design/first-spine-profile.md for the checkpoint, build identity, evidence
binding and resource limits. Mission control uses the same IPC/channel/record
contracts intended for the later autonomous endpoint.
